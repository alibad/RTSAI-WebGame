## Repeating a full release

```sh
python tools/prepare-inputs.py --committed --out <new>/inputs
python tools/prepare-ea-art.py plan --inputs <new>/inputs --out <new>/ea-plan.json   # then manifest/verify an extracted set
python tools/public.py --inputs <new>/inputs --out <new>/public-build --ea-art <new>/ea-art
python tools/prepare-gameplay-release.py --base D:/rtsai-map-release-20261018/data-startup/public \
  --gameplay <new>/public-build/data/public --out <new>/final/public --source <commit>
websim unpack --pack <new>/final/public/web-bundle.pack --root <new>/vfs-iso --audio
websim bake --root <new>/vfs-iso --maps all --out <new>/final/public/sprites
python tools/prepare-classic-soundtrack.py --base <published classic profile> --soundtrack <new>/final/public \
  --out <new>/final/public-classic --source <commit>          # then unpack/bake it the same way
node tools/build-public.mjs --data-only --data <new>/final/public --classic-data <new>/final/public-classic --out <new>/static
node tools/release-play.mjs prepare --data <new>/static --update "..."   # promote with the owner's approval
```

`build-public --data-only` needs some runtime in `final/public/wasm-aot`; the release tool builds and verifies the
real runtime from the same inputs, as it did here.
