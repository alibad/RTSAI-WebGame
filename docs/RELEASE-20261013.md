## What players get

In isometric mode America, Germany, England, France, Korea, Cuba, Libya, Iraq and Russia field the original Red
Alert 2 art for everything they build, with the original cameos. EA's notice ("EA has not endorsed and does not
support this product.") is on the main menu, the skirmish and campaign screens and in `/play/NOTICE`. No EA audio,
music or video is published. Unchanged: the seven modern factions, the Classic/top-down mode, every sound.

Known differences, as documented in [DEPLOY-PUBLIC.md](DEPLOY-PUBLIC.md#original-westwood-art-isometric-mode):
- five Soviet buildings (`napowr`, `nahand`, `nadept`, `natech`, `nanrct`) keep the project art: their footprints
  differ from Red Alert 2's;
- the ore purifier plug and the support-power cameos keep the project art;
- harvesters show no unload animation;
- mission enemies whose faction is Russia show the original art;
- the core download grows by about 1 MB (`web-bundle.pack` 5.3 → 6.3 MB brotli);
- the bundle changed, so saves, replays and peers from earlier builds are incompatible.

## Promotion and the Git link

`vercel deploy --prod` gave the new deployment only the team alias: `rtsai-play.vercel.app` stayed on the 12 October
deployment (`b34rah6pn`, built 11 October), because the project's automatic domain assignment was off. It had been
turned off by a rollback. Shortly before, the project had been linked to this GitHub repository, and a push to `main`
(`4c56434`) deployed the raw repository to production (`dpl_AfhNmPqhbrB2V8TLcn4EmN9oe6vR`, no build, no
`index.html`), which was rolled back. `vercel promote dpl_5tgv6mJFkMPH378HSpimsuFpqrHk` assigned the domains and
switched automatic assignment back on. Then `0e8f7e5` added the root `vercel.json` (`git.deploymentEnabled: false`) so
that pushes never deploy. The two pushes that followed (`0e8f7e5`, `617b918`) created no deployment.
